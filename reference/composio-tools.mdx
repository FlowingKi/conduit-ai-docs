---
title: Tools Commands
description: Lista completa de servicios y acciones disponibles para usar en el nodo Tool y en el chat con agentes.
---

Composio expone más de **1.052 servicios** con miles de acciones. Todas se pueden usar en:
- El **nodo Tool** del canvas (ejecución directa sin agente)
- El **chat con agentes** (el modelo llama la tool automáticamente cuando la necesita)

Para usar una acción, se escribe el slug exacto en el campo **Tool slug** del nodo Tool, o el agente la invoca por nombre en el chat.
