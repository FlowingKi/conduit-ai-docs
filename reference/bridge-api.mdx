El bridge es un servidor Express que corre en `http://localhost:3284`. La app web lo llama directamente desde el navegador (no pasa por Vercel).

## Autenticación

La mayoría de los endpoints requieren autenticación via header:

```
Authorization: Bearer <BRIDGE_TOKEN>
```

El token se configura en la primera ejecución del bridge y se almacena en Supabase asociado al equipo.

**Endpoints sin auth** (solo accesibles desde localhost):
- `GET /health`
- `POST /stop`
- `PUT /config/keys`
- `GET /config/keys/:service`
- `POST /config/setup`

---

## Endpoints de estado

### `GET /health`

Estado del bridge.

**Response:**
```json
{
  "status": "ok",
  "version": "0.1.0",
  "port": 3284,
  "bridgeUrl": "http://localhost:3284"
}
```

### `POST /stop`

Detiene el proceso del bridge. Usado por el tray icon.

**Response:** `{ "ok": true }`

## Configuración

### `PUT /config/keys`

Guarda una API key localmente (encriptada en el bridge). Usada por OpenAI, Google AI, DeepSeek.

**Body:**
```json
{
  "service": "openai",
  "apiKey": "sk-..."
}
```

**Response:** `{ "ok": true }`

### `GET /config/keys/:service`

Verifica si hay una key guardada para un servicio. No devuelve el valor.

**Response:** `{ "connected": true }`

### `POST /config/setup`

Configura el bridge en el primer uso (asocia al team, guarda token).

## Chat

### `POST /chat/run`

Ejecuta un chat con el modelo LLM configurado. Soporta Claude, OpenAI, Google AI, DeepSeek y Ollama.

**Body:**
```json
{
  "messages": [
    { "role": "user", "content": "Hola" }
  ],
  "systemPrompt": "Sos un asistente...",
  "model": "claude-sonnet-4-6",
  "localModels": [
    { "model_id": "llama3.2", "base_url": "http://localhost:11434" }
  ],
  "composioMcpUrl": "https://mcp.composio.dev/...",
  "agentId": "uuid",
  "workspaceId": "uuid"
}
```

**Response:** SSE stream con eventos:
```
data: {"type": "chunk", "text": "Hola, soy..."}
data: {"type": "tool_use", "label": "Ejecutando GITHUB_LIST_ISSUES"}
data: {"type": "done", "usage": {"input_tokens": 150, "output_tokens": 80}}
```

El campo `localModels` es la lista de modelos Ollama configurados. Si el `model` coincide con algún `model_id`, el bridge redirige el request a esa `base_url`.

## Tareas

### `POST /task`

Inicia una tarea larga en background (Claude Code ejecuta el prompt completo).

**Body:**
```json
{
  "prompt": "Creá un componente React para...",
  "agent_id": "uuid",
  "workspace_id": "uuid",
  "output_dest": { "type": "cloud" }
}
```

**Response:**
```json
{
  "taskId": "uuid",
  "streamUrl": "/stream/uuid"
}
```

### `GET /stream/:taskId`

SSE stream del progreso de una tarea.

**Eventos:**
```
data: {"type": "chunk", "text": "..."}
data: {"type": "tool_use", "label": "Escribiendo archivo..."}
data: {"type": "done", "code": 0}
```

## Archivos locales

Todos los endpoints `/local` requieren auth y operan sobre la carpeta local configurada en el workspace (`local_path`). Funciona con cualquier carpeta en disco — no requiere Obsidian.

### `POST /local/write`

Escribe un archivo en una ruta específica de la carpeta local.

**Body:**
```json
{
  "relativePath": "CONTEXT/decisiones/auth.md",
  "content": "# Decisión de auth\n...",
  "localPath": "/Users/juan/mis-notas"
}
```

**Response:** `{ "ok": true }`

### `GET /local/tree`

Árbol de carpetas completo desde la raíz (solo archivos `.md`). Devuelve `CONTEXT/` y `MEMORY/` como nodos raíz.

**Query:** `?localPath=...`

**Response:**
```json
{
  "tree": [
    { "name": "CONTEXT", "type": "folder", "children": [
      { "name": "sesiones", "type": "folder", "children": [
        { "name": "sesion-2026-07-28.md", "type": "file", "path": "CONTEXT/sesiones/sesion-2026-07-28.md" }
      ]}
    ]},
    { "name": "MEMORY", "type": "folder", "children": [] }
  ]
}
```

### `GET /local/file`

Contenido de un archivo específico.

**Query:** `?path=CONTEXT/decisiones/auth.md&localPath=...`

**Response:** `{ "ok": true, "content": "# Decisión...", "path": "CONTEXT/decisiones/auth.md" }`

### `GET /local/search`

Búsqueda de texto en la carpeta local.

**Query:** `?q=autenticación&localPath=...`

### `POST /local/extract-facts`

Compara el contenido de la carpeta local con los hechos existentes en Memory y propone solo los nuevos.

**Body:**
```json
{
  "relativePath": "CONTEXT/sesiones",
  "existingFacts": ["El proyecto usa TypeScript", "..."],
  "localPath": "/Users/juan/mis-notas"
}
```

**Response:**
```json
{
  "proposals": ["Nuevo hecho detectado"],
  "contradictions": [{"fact": "...", "conflictsWith": "..."}],
  "skipped": 2
}
```

### `POST /local/setup`

Crea la estructura canónica de carpetas (`CONTEXT/`, `CONTEXT/sesiones/`, `CONTEXT/agentes/`, `MEMORY/`, `MEMORY/notes/`).

**Body:** `{ "localPath": "/Users/juan/mis-notas" }`

### `POST /local/delete`

Elimina un archivo o carpeta de la carpeta local.

**Body:** `{ "relativePath": "MEMORY/notes/viejo.md", "localPath": "/Users/juan/mis-notas" }`

## Puerto y URL

El bridge corre en el puerto `3284` por defecto. La URL base es `http://localhost:3284`.

La app web detecta el bridge en `http://localhost:3284/health` al cargar. Si no responde, muestra el banner de bridge offline.
