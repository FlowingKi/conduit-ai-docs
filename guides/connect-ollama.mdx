---
title: Conectar Ollama
description: Configurá Ollama para correr modelos de IA localmente — sin API keys, sin costo por token.
---

Ollama te permite correr modelos de IA (Llama, Mistral, Gemma, etc.) directamente en tu computadora, sin enviar datos a servidores externos. Es la opción más privada y no tiene costo por token.

## Paso 1 — Instalar Ollama

1. Descargá Ollama desde [ollama.com](https://ollama.com)
2. Instalalo siguiendo las instrucciones para tu sistema operativo
3. Verificá que esté corriendo — abrí una terminal y ejecutá:
   ```bash
   ollama list
   ```
   Si muestra una lista (o vacía sin error), Ollama está activo.

## Paso 2 — Descargar un modelo

```bash
# Modelos recomendados para empezar
ollama pull llama3.2        # 2GB — rápido y capaz
ollama pull gemma3          # 5GB — muy buena calidad
ollama pull mistral         # 4GB — bueno para código
```

Ollama corre en `http://localhost:11434` por defecto.

## Paso 3 — Agregar el modelo en Conduit AI

<Steps>
  <Step title="Abrí Connections → AI Models">
    Buscá **Ollama** y hacé clic en **Conectar**.
  </Step>
  <Step title="Completá el formulario">
    - **Model ID**: el nombre exacto del modelo que descargaste (ej: `llama3.2`, `gemma3`, `mistral`)
    - **URL del servidor**: `http://localhost:11434` (el default de Ollama)
  </Step>
  <Step title="Hacé clic en Agregar modelo">
    El modelo queda guardado. Repetí este paso para cada modelo que quieras usar.
  </Step>
</Steps>

<Note>
Podés agregar múltiples modelos de Ollama — cada uno aparece como opción separada en el selector de modelos de los agentes.
</Note>

## Requisitos

- Ollama tiene que estar corriendo **mientras usás Conduit AI** — es un proceso local
- El bridge también tiene que estar activo para que la comunicación funcione
- Necesitás suficiente RAM: mínimo 8GB para modelos de 7B, 16GB+ para modelos más grandes

## Modelos disponibles (ejemplos)

| Modelo | Tamaño | RAM mínima | Mejor para |
|--------|--------|------------|------------|
| `llama3.2` | 2GB | 8GB | Uso general, rápido |
| `gemma3` | 5GB | 8GB | Calidad alta, instrucciones |
| `mistral` | 4GB | 8GB | Código, análisis |
| `llama3.1:70b` | 40GB | 64GB | Máxima calidad local |

## Gestionar modelos

Los modelos Ollama que agregaste están disponibles en **Settings → Local Models**. Desde ahí podés ver y eliminar los que ya no uses.
