Los agentes son el núcleo de Conduit AI. Cada agente es una IA especializada con su propio modelo, personalidad y conjunto de skills. Podés tener varios agentes con roles diferentes — uno para código, uno para investigación, uno para tareas administrativas.

## Crear un agente

1. Abrí **Agents** en el menú lateral
2. Hacé clic en **Nuevo agente**
3. Completá el formulario y guardá

## Campos de configuración

### Modelo

Elegís qué LLM usa el agente. Los modelos disponibles dependen de qué providers conectaste en **Connections**.

| Modelo | Cuándo usarlo |
|--------|---------------|
| `claude-sonnet-4-6` | Uso general, código, análisis — el más equilibrado |
| `claude-opus-4-8` | Máxima capacidad de razonamiento |
| `claude-haiku-4-5` | Respuestas rápidas, tareas simples, bajo costo |
| `gpt-4o` | Requiere OpenAI conectado |
| `gemini-1.5-pro` | Requiere Google AI conectado — contexto de 1M tokens |
| `gemini-1.5-flash` | Veloz y económico |
| `deepseek-chat` | DeepSeek V3 — muy económico, bueno para código |
| Modelos Ollama | Requiere Ollama corriendo + bridge activo |

### Personalidad

Tres parámetros que ajustan el comportamiento del agente:

**Tono**
- `Formal` — respuestas estructuradas, sin contracciones
- `Balanceado` — default, natural y claro
- `Casual` — conversacional, directo

**Largo de respuesta**
- `Breve` — respuestas cortas, al punto
- `Normal` — equilibrado
- `Detallado` — explicaciones exhaustivas

**Creatividad** (temperature 0.0–1.0)

Un slider que controla la aleatoriedad del modelo. `0.0` = determinista y preciso. `1.0` = creativo y variado.

- Para código y análisis → valores bajos (0.2–0.4)
- Para escritura creativa → valores altos (0.7–0.9)

**Instrucciones adicionales**

Campo de texto libre para el system prompt del agente. Definí el rol, restricciones o contexto específico del agente.

### Destino de archivos

Dónde guarda el agente los archivos que produce:

| Destino | Descripción |
|---------|-------------|
| ☁️ Cloud | Archivos guardados en Supabase — accesibles desde cualquier dispositivo |
| 📁 Local | Archivos en tu máquina, vía el bridge |
| 🔗 Connector | Archivos enviados a un conector externo (Composio) |

### Skills asignados

Los skills amplían las capacidades del agente. Para asignarlos, hacé clic en **+ Agregar** en la sección Skills del modal del agente. Se abre un picker con dos tabs:

- **📁 Local** — skills de las fuentes locales configuradas en tu equipo
- **☁️ Conduit** — skills guardados en la plataforma

Podés buscar por nombre y filtrar por tags. Los skills seleccionados aparecen como chips en el modal.

Ver [Skills](/concepts/skills) para más detalle.

#### Modo de carga de skills (`skill_load_mode`)

Controlá cuándo se inyecta el contenido de los skills en el contexto del agente:

| Modo | Comportamiento |
|------|---------------|
| **Siempre** | El contenido completo de cada skill se incluye en cada mensaje (default) |
| **Por contexto** | El contenido se inyecta solo si el mensaje del usuario menciona palabras clave del skill |

El modo "Por contexto" es útil cuando tenés muchos skills asignados y querés evitar saturar el contexto del agente con información irrelevante para cada mensaje puntual.

### Identidad del agente (Soul)

Cada agente tiene una nota de identidad en `CONTEXT/agentes/{nombre}/soul/_prompt.md` que se inyecta como primer bloque del system prompt. Esta nota define la identidad del agente dentro de la plataforma Conduit AI — qué secciones conoce, qué puede hacer, cuáles son sus reglas de comportamiento.

El soul se crea automáticamente cuando agregás un agente al workspace.

## Estados del agente

| Estado | Significado |
|--------|-------------|
| `activo` | Disponible para recibir tareas |
| `inactivo` | Pausado manualmente |
| `error` | Hubo un problema en la última tarea |

## Tokens y consumo

Cada agente tiene un contador de tokens acumulados visible en [Monitor](/concepts/monitor). Útil para optimizar el uso de modelos y controlar costos.
