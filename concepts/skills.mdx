Los skills son paquetes de instrucciones, comportamientos y herramientas que podés asignar a los agentes para ampliar sus capacidades. Un skill puede ser tan simple como un prompt de sistema o tan complejo como una integración con una herramienta externa.

## Tipos de skill

| Tipo | Descripción | Cuándo usarlo |
|------|-------------|---------------|
| `skill` | Instrucción de comportamiento general | Definir cómo actúa el agente en un dominio |
| `hook` | Se ejecuta en un momento específico del flujo | Acciones automáticas (al iniciar sesión, al guardar, etc.) |
| `prompt` | Prompt de sistema adicional | Inyectar contexto o restricciones extra |
| `tool` | Herramienta externa que el agente puede llamar | Integrar APIs, funciones, scripts |

## Paquetes de skills

Los skills se organizan en **paquetes**. Un paquete es una colección de skills relacionados — podés importar un paquete de GitHub con un comando, o crearlo manualmente.

Ejemplo de estructura de paquete:
```
mi-paquete/
├── SKILL.md          # Metadata del paquete
├── code-style.md     # Skill de estilo de código
├── git-workflow.md   # Skill de workflow git
└── testing.md        # Skill de testing
```

## Fuentes de skills

### Conduit Skills

Skills guardados en la plataforma Conduit AI. Los creás desde la pantalla **Skills** y están disponibles para todos los agentes del equipo.

### Fuentes locales

Podés apuntar a carpetas en tu máquina (vía el bridge) como fuentes de skills locales. El bridge escanea esas carpetas en dos niveles:

- **Carpeta con `SKILL.md`** → se registra como skill individual
- **Carpeta sin `SKILL.md`** con subcarpetas que sí tienen `SKILL.md` → se registra como paquete colapsable

Para agregar una fuente local:
1. Abrí **Skills** en el menú lateral
2. En el sidebar izquierdo, sección **Fuentes locales**, hacé clic en **+**
3. Ingresá la ruta absoluta a la carpeta
4. Los skills aparecen agrupados por paquete, con dividers alfabéticos

## Tags

Los skills tienen un sistema de tags con 57 etiquetas organizadas en 6 dimensiones:

| Dimensión | Ejemplos |
|-----------|---------|
| Dominio | `security`, `architecture`, `testing`, `design` |
| Scope | `file`, `project`, `team` |
| Modo | `review`, `generate`, `analyze` |
| Output | `code`, `document`, `analysis` |
| Momento | `before-coding`, `while-coding`, `after-coding` |
| Categoría | `ai-agents`, `devops`, `research` |

Los skills sin tags muestran un punto naranja `●`. Podés filtrar por tags usando los chips en la parte superior de la lista.

### Auto-etiquetado

Hacé clic derecho sobre cualquier skill local → **Auto-etiquetar**. El bridge lee el contenido del skill y usa el LLM para asignar los tags correspondientes automáticamente. El punto naranja desaparece cuando el skill tiene tags.

## Crear un skill

### Con asistente de IA

1. Abrí **Skills** en el menú lateral
2. Hacé clic en **Nuevo skill**
3. Describí qué querés que haga el skill
4. El asistente genera el frontmatter YAML y el contenido

### Manual (YAML)

Cada skill es un archivo Markdown con frontmatter:

```yaml
---
name: mi-skill
type: skill
description: Descripción de lo que hace este skill
tags: [architecture, review, after-coding]
---

Contenido del skill en Markdown...
```

Ver [Formato de skill](/reference/skill-format) para la referencia completa del frontmatter.

## Asignar skills a agentes

En el modal del agente, la sección **Skills** tiene un botón **+ Agregar** que abre un picker con:

- **Tab 📁 Local** — skills de las fuentes locales configuradas
- **Tab ☁️ Conduit** — skills guardados en la plataforma

Podés buscar por nombre y filtrar por tags. Los skills seleccionados aparecen como chips.

Ver [Modo de carga de skills](/concepts/agents#modo-de-carga-de-skills-skill_load_mode) en la doc de Agentes para controlar cuándo se inyecta el contenido de cada skill.

## Importar desde GitHub

Podés importar paquetes de skills desde repositorios públicos de GitHub. El paquete se descarga y queda disponible para asignar a cualquier agente.

1. Abrí **Skills → Importar**
2. Pegá la URL del repositorio
3. El sistema descarga y registra todos los skills del paquete

## Hooks

Los skills de tipo `hook` se ejecutan automáticamente en momentos específicos. El campo `tools` en el frontmatter define qué herramientas del sistema puede usar el hook.

```yaml
---
name: session-start
type: hook
description: Se ejecuta al iniciar una sesión de trabajo
tools: memory_read, workspace_context
---
```

Los hooks activos para un agente se ejecutan sin necesitar una instrucción explícita del usuario.
